Acerca del Proyecto

Materia: Informática General 2026

Cátedra: Valeria Drelichman, Pedro Paleo, Leonardo Nadel, Norma Morales

Desarrollador: Gabi Raimundo

Tecnologías y Enfoque Técnico

  • HTML5 Semántico: Estructura accesible con tags de encabezado, navegación y secciones.
  • CSS3 Moderno: Variables personalizadas, flexbox y diseño responsive unificado en una única hoja de estilos.
  • JavaScript Vanilla: Manipulación dinámica del DOM, listeners de eventos, asincronía (Fetch API con async/await), temporizadores (setInterval/clearInterval) y persistencia mediante JSON + LocalStorage.
